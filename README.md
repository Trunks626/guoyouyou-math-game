# 郭酉酉学算术

一个专为小朋友设计的 20 以内加减法学习游戏。

## ✨ 功能特色

- **📚 学习模式**：用可爱的动画物体演示加减法原理
- **🎮 练习模式**：三个难度等级，互动答题即时反馈
- **🏆 成就系统**：累计星星、正确率统计、连续答对奖励
- **🎨 精美设计**：卡通风格界面，专为儿童优化

## 🎯 难度分级

| 等级 | 范围 | 说明 |
|------|------|------|
| 🌱 入门 | 10以内 | 适合刚开始学习的小朋友 |
| 🔥 进阶 | 15以内 | 巩固基础后的提升 |
| 👑 挑战 | 20以内 | 全面掌握加减法 |

## 🛠️ 技术栈

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Framer Motion
- Capacitor
